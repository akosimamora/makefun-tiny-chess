A chess engine in under 4,096 bytes of Python 3.13 standard library only: 0x88 board, alpha-beta with quiescence, transposition table, killer-move ordering, piece-square evaluation. Plays the make.fun house gauntlet through the env. No model calls, no clock in the search — a fixed node budget per move, so every trial replays identically.
